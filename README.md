# Smart Budget Manager

## What does it do?
Smart Budget Manager (`SmartBudget_Manager.xlsx`) is a simple, automated Excel workbook designed for a small company to record monthly income, categorize expenses, and track budget limits. It automatically calculates your balance and provides visual charts and overspending warnings so you always know your financial status.

## What is needed to use it?
To run this workbook, you need Microsoft Excel 2016, 2019, 2021, Microsoft 365, or an equivalent compatible spreadsheet software.

## How to get started?
1. Open the `SmartBudget_Manager.xlsx` file.
2. Navigate to the **Categories** worksheet to review predefined spending categories (e.g., Food, Transport, Rent, Health, Education).
3. Go to the **Transactions** worksheet to begin logging your income and expenses.
4. Check the **Dashboard** to view your total balance and visual charts.
